About

Armenta-Lib

This preview is based on the actual public entrypoint FyyUI.Menu(options) and its real Menu:Tab / Tab:* component factories. It intentionally surfaces the library's own theme families and callback options rather than generic settings.

  • Default theme: Dark
  • Window default size: 601 × 344
  • Responsive: true by default
  • Official themes: Dark, Light, Amoled and accent themes
